# Workflow: Open PDF

## Goal

Open a PDF document within the workspace.

PDF documents are frequently used as genealogy sources.

The document should remain integrated into the research workflow.

---

## Starting Point

A PDF is linked to:

- Person
- Family
- Event
- Source

The PDF is visible within a media section.

---

## User Flow

1. The user selects a PDF document.

2. Ancestra opens the PDF in a new workspace tab.

Example:

[ Family Card ]
[ BirthCertificate.pdf ]

3. The PDF Viewer becomes the active workspace view.

4. The PDF is displayed directly within the central workspace.

5. The Inspector displays PDF metadata.

Examples:

- Filename
- Page Count
- File Size
- Linked Objects

6. The user may switch between tabs at any time.

7. The user may close the PDF tab independently from the associated genealogy object.

---

## Result

The PDF is displayed within the workspace.

Research context remains available through tabs.

---

## UX Goals

- Immediate document access
- No external PDF reader
- Consistent workspace behavior
- Fast switching between genealogy data and source documents

---

## UX Principles Applied

### Information Opens In Tabs

PDF documents open in workspace tabs.

### Workspace Instead Of Database Application

Source documents become part of the research workflow.

### Every Workspace Area Has Purpose

The workspace displays the document.
The Inspector displays document context.

### Preserve Orientation

The original research object remains available through tabs.

---

## Future Considerations

Future versions may support:

- OCR integration
- Text extraction
- Search within PDF
- Side-by-side source comparison

These additions must preserve the workspace workflow.

---

## Success Criteria

The workflow is successful when:

- PDFs open immediately.
- No external PDF application is required.
- Users can switch seamlessly between documents and genealogy data.
- Research context remains preserved.
