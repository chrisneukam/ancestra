# Workflow: Open Image

## Goal

Open an image within the workspace.

Supported image formats include:

- JPG
- JPEG
- PNG
- TIFF

The image should be displayed directly within the central workspace.

---

## Starting Point

An image is linked to:

- Person
- Family
- Event
- Source

The image is visible within a media section.

---

## User Flow

1. The user selects an image.

2. Ancestra opens the image in a new workspace tab.

Example:

[ Family Card ]
[ Portrait.jpg ]

3. The image viewer becomes the active workspace view.

4. The image is displayed immediately.

5. The Inspector displays image metadata.

Examples:

- Filename
- Resolution
- File Size
- Linked Objects

6. The user may close the tab at any time.

---

## Result

The image is visible within the workspace.

The original research context remains available through tabs.

---

## UX Goals

- Immediate visual access
- No external application required
- Consistent tab workflow
- Preserve research context

---

## UX Principles Applied

### Information Opens In Tabs

Images open as workspace tabs.

### Workspace Instead Of Database Application

Media becomes part of the research workflow.

### Every Workspace Area Has Purpose

The workspace displays content.
The Inspector displays image context.

---

## Future Considerations

Future versions may support:

- Zoom
- Pan
- Side-by-side comparison
- Annotation layers

These features must preserve workspace consistency.

---

## Success Criteria

The workflow is successful when:

- Images open immediately.
- No external viewer is required.
- The image remains part of the workspace workflow.
