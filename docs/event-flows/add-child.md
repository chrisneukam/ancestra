# Add Child

## Purpose

Defines the interaction flow for creating a child within a family.

---

# Flow

Family Card active

↓

User enters Child

↓

Child Person created

↓

Child added to Family

↓

Family State updates

↓

Timeline updates

↓

Navigator Context updates

↓

Inspector Context updates

---

# Result

Child becomes part of the genealogy graph.

Workspace Focus remains Family.
