# Open Family

## Purpose

Defines the interaction flow for opening a family.

---

# Triggers

A family may be opened from:

- Navigator
- Search
- Person Card
- Inspector

---

# Flow

User selects Family

↓

Workspace opens Family

↓

Family Tab becomes active

↓

Workspace Focus changes

↓

Navigator reflects Family

↓

Inspector reflects Family

---

# Result

Active Workspace Object

= Family

Current Focus

= Family

Navigator Context

= Family

Inspector Context

= Family
