# Preview To Persistent

## Purpose

Defines how exploratory navigation becomes committed work.

---

# Flow

User opens object

↓

Preview Tab created

↓

User edits data

↓

Preview Tab promoted

↓

Persistent Tab created

---

# Focus

Workspace Focus remains unchanged.

Navigator remains unchanged.

Inspector remains unchanged.

---

# Invariant

Navigation opens Preview Tabs.

Editing creates Persistent Tabs.
