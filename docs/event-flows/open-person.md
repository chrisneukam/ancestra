# Open Person

## Purpose

Defines the interaction flow for opening a person.

The workflow applies regardless of entry point.

---

# Triggers

A person may be opened from:

- Navigator
- Search
- Family Card
- Inspector

---

# Flow

User selects Person

↓

Workspace opens Person

↓

Person Tab becomes active

↓

Workspace Focus changes

↓

Navigator reflects Person

↓

Inspector reflects Person

---

# Result

Active Workspace Object

= Person

Current Focus

= Person

Navigator Context

= Person

Inspector Context

= Person

---

# Notes

Open Person always results in a workspace focus change.

Workspace remains the single source of truth.
