# Person Example

## Purpose

This example illustrates how a Person is represented within the genealogy domain.

Person = Identity

---

# Example

Person

- Name: John Doe
- Sex: Male

Events

- Birth (1845)
- Death (1912)

Families

- Parents Family
- Marriage Family

Research Assets

- Birth Certificate
- Portrait Photograph
- Research Notes

---

# Observations

The Person owns genealogy facts.

The Person represents identity.

Relationships and family context are discovered through connected families.
